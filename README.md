# 📊 Grupo 14 – Trujillo & Gutiérrez – MD1

Repositorio que contiene los proyectos desarrollados para la asignatura **Minería de Datos 1 (MD1)**.  
Cada proyecto aborda diferentes procesos de análisis, transformación y visualización de datos aplicando técnicas de minería de datos.

---

# 📖 Descripción del Proyecto

Este repositorio reúne los diferentes proyectos realizados durante el curso de **Minería de Datos**, enfocados en la obtención, procesamiento, análisis y visualización de datos.

Cada proyecto sigue un flujo de trabajo que incluye:

- Obtención de datos
- Limpieza y transformación
- Análisis exploratorio
- Visualización de información
- Interpretación de resultados

Estos proyectos permiten aplicar conocimientos de **analítica de datos, procesamiento de información y generación de insights**.

---

# 🎯 Objetivo del Proyecto

Desarrollar soluciones de análisis de datos que permitan:

- Procesar grandes volúmenes de información.
- Identificar patrones y tendencias en los datos.
- Apoyar la toma de decisiones mediante visualizaciones y análisis.
- Aplicar metodologías de minería de datos en escenarios reales.

---

# 🗂 Descripción de los Datos

Los datasets utilizados en los proyectos pueden provenir de diferentes fuentes como:

- APIs públicas
- Conjuntos de datos abiertos
- Datos recolectados mediante procesos ETL
- Bases de datos relacionales

Los datos contienen información que permite realizar análisis estadísticos, exploración de patrones y visualización de resultados.

---

# 🚀 Alcance

Los proyectos incluidos en este repositorio contemplan:

- Procesos de **extracción de datos**
- **Transformación y limpieza de información**
- **Análisis exploratorio de datos (EDA)**
- **Construcción de visualizaciones**
- Documentación de resultados

El objetivo es demostrar el uso de herramientas de **ciencia de datos y minería de datos** en el análisis de información.

---

# 🛠 Herramientas Utilizadas

Las principales tecnologías utilizadas en los proyectos son:

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib / Plotly**
- **Streamlit**
- **PostgreSQL**
- **Git y GitHub**

Estas herramientas permiten desarrollar pipelines de datos y dashboards interactivos.

---

# 💡 Solución

La solución propuesta consiste en implementar procesos que permitan:

1. Extraer información desde diferentes fuentes de datos.
2. Transformar los datos para su correcta utilización.
3. Analizar los datos mediante técnicas estadísticas y de minería de datos.
4. Presentar los resultados mediante visualizaciones y dashboards interactivos.
